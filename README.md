# 🏡 今天也要好好生活 · 温暖小屋

一个单文件、零依赖、打开即用的温馨页面。

![预览说明](https://img.shields.io/badge/HTML-单文件-eb9f85) ![无依赖](https://img.shields.io/badge/依赖-无-f7cfc0) ![License](https://img.shields.io/badge/License-MIT-5a463c)

## ✨ 它有什么

- **跟着时间问候你**：凌晨、清晨、上午、午后、傍晚、深夜，问候语和时间一起变化
- **实时时钟**：精确到秒的日期与时间显示
- **暖心话语**：15 句温柔的话随机出现，点「再来一句」或按 <kbd>空格</kbd> 更换
- **点击飘落的小爱心**：页面任意位置点一下，就会开出小花
- **一点点音效**：点「把温暖送给屏幕」会响起三声柔和的风铃声
- **漂亮的细节**：奶油渐变背景、缓慢漂浮的光球、呼吸的暖光、毛玻璃卡片
- **为每个人考虑**：手机适配、尊重系统「减弱动态效果」、可打印、无外部请求（离线可用）

## 🚀 怎么用

直接双击 `zhanghaoqun-0410-work1.html`，用浏览器打开就行。不需要安装任何东西。

想改内容？整个页面只有 zhanghaoqun-0410-work1html` 一个文件：

| 想改什么 | 改哪里 |
| --- | --- |
| 问候语 | `<script>` 里的 `HOUR_GREETING` 数组 |
| 暖心话 | `<script>` 里的 `QUOTES` 数组 |
| 配色 | `<style>` 顶部的 `:root` 变量（`--cream`、`--blush`、`--rose` …） |
| 页脚文字 | `<footer>` 那块 |
